# Customer Value Product Design

This example demonstrates a customer-centric approach to product development. It simulates a scenario where a business first identifies core customer problems and then designs a product (a set of features) specifically to address those identified needs, rather than building a product first and then seeking customers. This highlights how starting with customer value is fundamental for sustainable growth.

## Language

`python`

## How to Run

Save the code as `customer_value_product.py` and run it from your terminal using `python customer_value_product.py`. Follow the prompts to select a customer problem, and the program will suggest product features designed to solve it.
